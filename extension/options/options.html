fox-webusb の設定

Firefoxはnavigator.usb (WebUSB) を実装していません (Mozillaの公式見解は "harmful")。この拡張機能は、ローカルで動くネイティブメッセージングホスト (Pythonプロセス)経由で実USB機器へアクセスすることで、同等のAPIを提供します。

セットアップ

  1. Python 3.9以上がインストールされていることを確認してください。
  2. このアドオンに同梱されている native-host/ フォルダで、次を実行します: 
    cd native-host
pip install -e .   # 仮想環境を使う場合はその中で。使わない場合は末尾に --break-system-packages を追加
python3 install.py
  3. (任意・推奨) より高速なbase64処理を使いたい場合は、Rustツールチェイン (rustc/cargo、1.74以上)がある環境で: 
    cd native/fox_webusb_accel
pip install maturin
maturin develop --release   # 開発機での利用時。配布時は maturin build --release → pip install
    ビルドしなくても標準のPython実装で完全に動作します。
  4. この拡張機能を about:debugging#/runtime/this-firefox の「一時的なアドオンを読み込む」から読み込んでください(extension/manifest.json を選択)。
  5. 上のステータスが緑色になれば準備完了です。

許可したオリジン

サイトが requestDevice() でユーザーに選ばせ、許可されたUSB機器の一覧です。

既知のデバイス

これまでに一度でも選択されたことのあるUSB機器の履歴です(デバイス選択ダイアログでの並べ替えに使われます。許可そのものとは別の情報です)。
